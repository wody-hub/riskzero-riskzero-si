# riskzero-si 사용 가이드 안내 (얇은 라우터)

## 역할

개발자의 질문을 분류하여 **`GUIDE.md`(이 스킬 디렉토리 상위, `../GUIDE.md`)의 해당 챕터만 발췌**해 답한다.

**핵심 원칙 — 콘텐츠를 이 파일에 두지 않는다.**
이 스킬은 라우터다. 답변 내용의 단일 출처는 GUIDE.md이며, 여기에 사용법을 복사해 적으면
다음 갱신 때 어긋난다. 답변할 때는 반드시 GUIDE.md를 읽고, 출처 챕터를 함께 표기한다.

## 사용하지 말아야 할 때

- riskzero-si와 무관한 일반 도움말, 다른 스킬 사용법 → 해당 스킬 문서 또는 일반 대화
- 파이프라인을 실제로 **실행**하려는 요청 → `/riskzero-si-pipeline` 등 해당 스킬
- 스킬 자체의 버그 신고 → 메인테이너 (GUIDE.md 부록 G 에스컬레이션)

## 실행 절차

1. **GUIDE.md 위치 확인** — 이 스킬 디렉토리 기준 `../GUIDE.md`. 없으면 `git pull` + `./setup` 재실행을 안내하고 중단한다.
2. **질문 분류** — 아래 라우팅 표에서 해당 챕터를 찾는다. 분류가 애매하면 목차(GUIDE.md 앞부분 ~160행)를 먼저 읽고 판단한다.
3. **해당 챕터만 Read** — 전체 파일(1,100줄+)을 한 번에 읽지 않는다. Grep으로 챕터 헤딩의 줄 번호를 찾고 offset/limit으로 그 범위만 읽는다.
4. **답변** — 발췌 내용 기반으로 답하고, 끝에 출처를 표기한다: `(출처: GUIDE.md N장)`. 더 깊은 내용이 있으면 관련 챕터를 안내한다.

## 라우팅 표 — 질문 유형 → GUIDE.md 챕터

| 질문 유형 | 챕터 | Grep 패턴 |
|---|---|---|
| 왜 이렇게 일하나 / 철학 | 1장 | `^## 1장` |
| 구성 요소 (gstack, si-config 관계) | 2장 | `^## 2장` |
| 전체 흐름 / 지금 어느 단계 | 3장 | `^## 3장` |
| 설치 / 셋업 / --init | 4장 + 부록 C | `^## 4장`, `^## 부록 C` |
| 처음 시작 / 온보딩 | 5장 + 5일 로드맵 | `^## 5장`, `마스터 로드맵` |
| 입력 소스 준비 (기획서/퍼블/DDL) | 6장 | `^## 6장` |
| STEP 1 계획 / 두뇌풀가동 | 7장 | `^## 7장` |
| STEP 2 계획 리뷰 | 8장 | `^## 8장` |
| STEP 3 구현 / 코드노예 / TDD | 9장 + 21장 | `^## 9장`, `^## 21장` |
| STEP 4 표준 리뷰 | 10장 | `^## 10장` |
| STEP 5 PR 리뷰 | 11장 | `^## 11장` |
| STEP 6 QA 체크리스트 / 더미데이터 | 12장 | `^## 12장` |
| STEP 7 버그 수정 | 13장 | `^## 13장` |
| STEP 8 최종 검증 / 완료 기준 | 14장 (DoD 포함) | `^## 14장` |
| 구간 실행 / --from --to | 15장 | `^## 15장` |
| 역할별 (신입/리뷰어/QA/팀리드) | 16장 | `^## 16장` |
| BE/FE 분리 / 병렬 | 17장 | `^## 17장` |
| 스킬 단독 사용 | 18장 | `^## 18장` |
| 언제 쓰면 안 되나 | 19장 | `^## 19장` |
| 게이트 / 리뷰 실패 / 복귀 | 20장 | `^## 20장` |
| 안전장치 (서버 게이트, 덮어쓰기) | 22장 | `^## 22장` |
| 실제 사례가 궁금 | PART V 사례 1~3 | `^## 사례` |
| 규칙 / 원칙 | 부록 A | `^## 부록 A` |
| 어떤 말에 어떤 스킬이 뜨나 | 부록 B | `^## 부록 B` |
| 명령/옵션 전체 목록 | 부록 D | `^## 부록 D` |
| 산출물이 어디 생기나 | 부록 E | `^## 부록 E` |
| 용어 뜻 | 부록 F | `^## 부록 F` |
| 안 될 때 / 에러 | 부록 G | `^## 부록 G` |
| 하지 말아야 할 패턴 | 부록 H | `^## 부록 H` |
| 어떤 모델 쓸까 | 부록 I | `^## 부록 I` |

## 답변 스타일

- 질문이 짧으면 답도 짧게 — 챕터 전체를 옮겨 적지 않고 핵심만 발췌한다
- 명령어는 그대로 인용한다 (예: `/riskzero-si-pipeline {기능명} --from=3`)
- 여러 챕터에 걸치는 질문은 가장 직접적인 챕터로 답하고 나머지는 "자세히는 N장" 안내
- 산출물 없음 — 이 스킬은 파일을 만들지 않는다
