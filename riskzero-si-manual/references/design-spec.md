## 슬라이드 유형 5종

### 1. 표지
- 파란 블록(4A86E8) x=0.79 y=3.00 w=6.69 h=1.57: `GH`(48pt) `경기주택도시공사` `User Guide`(35pt)
- 아래 대상 라벨: `관리자 | WEB` (18pt, 666666)

### 2. 목차 (Contents)
- 제목 "Contents" y=0.79
- 2단 구성. 행: `장그룹(시작하기/PLAN/Check…) | 절번호(1-1.) | 절제목 | 페이지번호 p`
- 장 그룹명은 볼드, 절 행은 회색

### 3. 장 간지
- 큰 장 번호 `1.` (60pt) y=2.07
- 장 제목 `시작하기` (36pt) y=2.96
- 장 설명 한 줄 (15pt) y=3.77

### 4. 콘텐츠 페이지 (핵심)
위에서 아래로:

1. **브레드크럼** x=0.79 y=1.32 h=0.35 — `사용자 매뉴얼 > {장} > {절번호}. {절제목}` 9pt 666666
2. **제목바** x=0.79 y=2.07 w=6.69 h=0.63 — 4285F4 채움, 흰 볼드 17~18pt `{절번호}. {절제목}`,
   우측에 흰 픽셀 데코 사각형 클러스터(0.31/0.16/0.08 크기 6~8개)
3. **주요 설명 박스** y=3.41 h=0.49+ — 파란 테두리 박스, 볼드 라벨 `주요 설명` + `·` 회색 설명문.
   설명문 안에서 핵심 구는 파란 볼드 인라인 강조
4. **기능 블록** × N:
   - 기능 라벨 (볼드 검정, 예: `가입하기`, `접속하기`, `설정하기`, `조회`, `등록하기`)
   - 본문 (회색 434343). **버튼·메뉴명은 '파란 볼드'로 인라인 강조** (작은따옴표 포함)
   - 스크린샷: **기능 영역 크롭**(전체 화면 덤프 아님 — 원본 214개 중 181개 와이드 크롭),
     CCCCCC 테두리, 필요 시 좌측 파란 엣지바(w=0.19)
   - **마커**: 스크린샷 위 0.24in 원(4285F4 채움, 흰 테두리 1.5pt, 흰 숫자 9pt)
   - **마커 설명행**: 파란 ❶❷❸ 딩벳 + 회색(595959) 10pt 설명
5. **Tip's 박스** (옵션) — 테두리 박스, 볼드 `Tip's` 제목 + 본문 10pt. 핵심 구 볼드

### 5. 연속 페이지
- 절 내용이 한 페이지를 넘으면 브레드크럼만 유지하고 제목바 없이 이어감
- 마커 번호는 절 내에서 연속 (❼❽…)

## 공통 헤더/푸터 (모든 본문 페이지)

- 우상단: `GH`(파랑 볼드) ` User Guide`(검정 볼드) 12pt + 아래 가로 구분선 (y≈1.0)
- 좌하단: GH 로고 이미지
- 우하단: 페이지 번호 (y=10.51)

## 콘텐츠 작성 규칙 (문체)

- 경어체 안내문: "~해 주시기 바랍니다", "~하실 수 있습니다"
- 마커 설명은 화면 요소의 **역할**을 설명 (무엇인지 + 무엇을 할 수 있는지)
- `주요 설명`은 1~2문장으로 화면의 목적 요약
- Tip's는 예외 상황·제한 사항 안내 (유효 시간, 권한 요청 등)
